Abstract
ReWear is a web-based platform designed to promote sustainable fashion by enabling users to exchange, donate, and reuse pre-owned clothing. The increasing consumption of clothing contributes to textile waste, while many usable garments remain unused or are discarded. ReWear addresses this problem by connecting individuals who want to give away or exchange clothing through a centralized digital platform. Users can register, upload clothing listings with images and details such as category, size, condition, and availability, and browse items shared by other users. The platform provides search and filtering capabilities to help users find suitable clothing and an exchange request mechanism to manage requests, approvals, and transaction status. An administrative dashboard enables the management of listings, reported content, and user activity. By encouraging clothing reuse and community participation, ReWear aims to reduce textile waste, improve access to affordable clothing, and promote responsible consumption. The platform demonstrates the practical application of web development, database management, user authentication, and digital marketplace technologies while supporting environmental sustainability.

Objectives
Develop a centralized platform for clothing exchange, donation, and reuse.
Enable users to create, manage, search, and filter clothing listings.
Implement an exchange request system to facilitate interactions between users.
Provide secure user authentication and manage clothing availability and request status.
Develop an administrative dashboard to manage listings, reports, and user activity.
Encourage sustainable fashion practices and reduce unnecessary textile waste.

Key Features
User Registration and Login: Allows users to create accounts and securely access the platform.
Clothing Listings: Enables users to upload clothing images and provide item details, including category, size, condition, and description.
Search and Filtering: Helps users discover clothing based on size, category, condition, and availability.
Exchange Requests: Allows users to request available items or propose clothing exchanges.
Request Management: Enables users to accept, reject, and track exchange requests.
Donation Option: Allows users to list clothing items that are available to others at no cost.
User Dashboard: Displays uploaded items, received requests, sent requests, and their current statuses.
Admin Dashboard: Enables administrators to manage users, review listings, and handle reported content.
Clothing Availability Tracking: Updates item availability when an exchange or donation is completed.
Sustainability Awareness: Encourages the reuse of clothing and responsible consumption.

Expected Outcome
ReWear provides a simple and accessible platform for connecting people who want to exchange or donate pre-owned clothing. It simplifies clothing discovery and request management while encouraging reuse, reducing avoidable textile waste, and promoting sustainable fashion within the community.
